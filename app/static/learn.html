How to use Learn

Turn dense text into something you can actually study — an outline, a map, a quiz, and a check that the AI didn't drift from your source.
Get material in
→

Paste text directly into the box — an article, an email, your own notes, anything dense.

→

Import URL fetches a web page's text for you, server-side.

→

Import from Notes pulls in one of your existing Notes tabs.

Generate
1

Click Generate to build a plain-language outline, a mind map, and a quiz from whatever's in the source box.

2

Regenerate replaces all three — it'll ask you to confirm first if you've already got output, so you don't lose edits by accident.

The three views
→

Outline — small plain-language chunks with key terms called out. Edit any of it inline; it autosaves.

→

Map — the same material as a mind map, so you can see how the pieces relate. Edit map lets you hand-edit the raw diagram.

→

Quiz — try to answer in your head before clicking "Reveal answer." Retrieval like this beats re-reading for actually remembering something. Edit quiz lets you change or add/remove questions.

Check accuracy
!

Compares the outline and quiz against your source text and flags anything that isn't actually supported, or that contradicts it. It's checking faithfulness to your source, not fact-checking the source against the world — if the source itself is wrong, this won't catch that.

i

Any edit marks the check as stale and hides the badges until you recheck, so you always know whether what you're looking at has actually been verified.

A few ways to use it
★

A dense article or report — paste or Import URL, Generate, read the Outline first instead of the raw text.

★

Your own messy notes — Import from Notes, Generate, and turn rough notes into something structured enough to actually study from.

★

Self-testing before it matters — Quiz tab, answer before revealing, so you find the gaps before a real conversation or decision does.

★

Fixing something that's off — if a chunk or answer isn't quite right, edit it directly rather than accepting it as-is.

Custom topic mode
→

Switch to Custom topic on a new item, type what you want to learn (e.g. "cyber threat hunting"), and click Build plan — the AI lays out an ordered course of lessons.

→

Open any lesson from the Plan tab and click Generate lesson to write that lesson's content and quiz on demand — lessons aren't generated until you open them.

→

Check off lessons as you finish them to track progress through the plan.
