How agents work

What an agent needs, how skills work, and a couple of examples to copy.
The basics
1

Name & description are just for your own reference in the list — they don't affect the run.

2

Instructions are the prompt sent to the model. Be specific and tell it to reference real data (task names, digest contents) instead of generic advice.

Context
→

No context runs on your instructions alone — good for a fixed prompt that doesn't depend on recent activity.

→

Recent activity digest appends entries/tasks from a date range you pick each run, so the agent can reference what actually happened.

Ollama (local)
1

Install Ollama from ollama.com and make sure it's running in the background.

2

Pull a model, e.g. ollama pull llama3.2:3b, then pick it as the default in Admin → AI Provider.

3

That's it — no key needed. Agents set to Ollama use whatever model is active there.

Claude (cloud)
1

Grab an API key from console.anthropic.com.

2

Paste it into Admin → AI Provider and save — Raven checks it right away and shows a connected/error status.

3

Agents set to Claude use this key. Usage is billed to your Anthropic account per run.

Chaining agents
→

Set Runs after to another agent to build a pipeline — e.g. a digest builder feeds a summarizer. Clicking Run on the downstream agent runs the whole chain, and each link keeps its own run history.

Skills (Claude only)
!

Skills let an agent take real actions instead of just describing them. They only fire for Claude-powered agents — Ollama can't reliably call tools yet, so its agents stay text-only.

→

Create a task — e.g. "Review the digest. For anything that needs follow-up but isn't already a task, create one with a due date."

→

Complete a task — e.g. "If the digest shows a task's work was actually finished, mark it complete."

→

Log an entry — e.g. "After reviewing, log a one-line note summarizing what you found."

i

Every run shows an "Actions taken" list under its output, so you can see exactly what got created or changed — nothing happens silently.
