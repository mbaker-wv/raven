RAVEN - SETUP INSTRUCTIONS
===========================
Last updated: 2026-08-02

This guide covers four things:
  1. Installing Ollama (runs AI models locally on your machine)
  2. Installing the Llama 3.2 3B model
  3. Installing and running the Raven app
  4. Creating a desktop launcher to start it (Windows and macOS)

-----------------------------------------
1. INSTALL OLLAMA
-----------------------------------------

Ollama lets you run AI models locally instead of calling a cloud API.

Windows:
  Option A - winget (recommended):
    1. Open PowerShell
    2. Run:
         winget install Ollama.Ollama
    3. Restart your terminal after install so PATH updates take effect.

  Option B - manual download:
    1. Go to https://ollama.com/download
    2. Download and run the Windows installer
    3. Follow the install prompts

macOS:
    1. Go to https://ollama.com/download
    2. Download the macOS app and drag it into Applications
    (or run: brew install ollama)

Linux:
    curl -fsSL https://ollama.com/install.sh | sh

Verify it installed correctly:
    ollama --version

Ollama runs as a background service. If it's not already running, start it with:
    ollama serve

By default it listens at http://localhost:11434

-----------------------------------------
2. INSTALL THE LLAMA 3.2 3B MODEL
-----------------------------------------

With Ollama installed and running, pull the model:

    ollama pull llama3.2:3b

This downloads the 3-billion-parameter Llama 3.2 model (a few GB, so it may
take a few minutes depending on your connection).

Confirm it's available:

    ollama list

You should see "llama3.2:3b" in the list.

Quick test (optional):

    ollama run llama3.2:3b

Type a prompt to confirm it responds, then type /bye to exit.

Note: Raven uses "llama3.2:3b" as its default model (set via the
OLLAMA_MODEL environment variable, or overridden per-agent in Admin), so no
extra configuration is needed once this model is pulled.

-----------------------------------------
3. INSTALL THE RAVEN APP
-----------------------------------------

Prerequisites:
    - Python 3.11 or later
        Download: https://www.python.org/downloads/
        Windows: on the first install screen, check "Add python.exe to
          PATH" before clicking Install.
        macOS: the installer sets up PATH on its own - no checkbox to
          look for. Afterward, "python3" is the command to use (plain
          "python" usually isn't on PATH on macOS). If you have Homebrew,
          "brew install python" also works.
    - git
        Windows: https://git-scm.com/downloads (installer defaults are
          fine - just click through)
        macOS: run "git --version" in Terminal - if it's not already
          installed, macOS prompts you to install the Xcode Command Line
          Tools, which is all you need.
    - Ollama installed and running (see steps 1-2 above), OR a Claude API
      key if you plan to use Claude instead of local Ollama

Steps:

  1. Clone the repo (this is a private repo - see "SHARING WITH SOMEONE
     ELSE" below if you're setting this up for another person):
       git clone https://github.com/mbaker-wv/raven.git
       cd raven

  2. Create a virtual environment and install dependencies:

       Windows:
         python -m venv .venv
         .venv\Scripts\pip install -r requirements.txt

       macOS/Linux:
         python3 -m venv .venv
         .venv/bin/pip install -r requirements.txt

  3. (Optional) If you're restoring an existing database from backup
     instead of starting fresh - e.g. setting Raven up on a second
     machine - see RESTORE.md in this folder for the B2 restore steps.
     Importantly, that also covers copying over ".raven.key", a small
     file that isn't included in the backup itself but is needed to read
     your saved Claude/B2 credentials - skipping it doesn't lose any of
     your projects/tasks/notes, it just means re-entering those two keys
     in Admin afterward.

  4. Run the app (this starts the server directly in a terminal, opening
     your browser to it - useful for development. For everyday use, skip
     to section 4 below and use the desktop launcher instead):

       Windows:
         .venv\Scripts\python -m uvicorn app.main:app --port 8000

       macOS/Linux:
         .venv/bin/python -m uvicorn app.main:app --port 8000

  5. Raven opens your browser automatically a moment after startup. If it
     doesn't, go to:
       http://localhost:8000

Once running, go to Admin in the app to:
    - Confirm the AI provider is set to "ollama" (default) to use your
      local Llama 3.2 3B model, or switch to "claude" and add an API key
    - Set up Backblaze B2 backup credentials if desired

-----------------------------------------
4. CREATE A LAUNCHER
-----------------------------------------

Raven runs as a proper desktop app: the launcher starts the server in the
background and opens Raven in its own native window (via pywebview,
installed as part of "pip install -r requirements.txt" in step 3 above) -
no terminal window, no manually opening a browser tab. Closing the window
shuts the server down too.

Windows:

A launcher file named "start_raven_app.bat" is included in this folder.

To pin it to your desktop:

  1. Right-click "start_raven_app.bat" in this folder
  2. Choose "Show more options" (Windows 11) > "Send to" > "Desktop
     (create shortcut)"
     (On Windows 10, just "Send to" > "Desktop (create shortcut)")
  3. A shortcut named "start_raven_app.bat - Shortcut" will appear on your
     desktop. Rename it to "Raven" if you'd like.

Give it the Raven icon (included as "raven_icon.ico" in this folder):
  1. Right-click the desktop shortcut > Properties
  2. Click "Change Icon..."
  3. Click "Browse..." and select "raven_icon.ico" inside the folder you
     cloned the repo into (e.g. C:\path\to\raven\raven_icon.ico)
  4. Click OK > Apply

To launch Raven going forward:
  1. Make sure Ollama is running (it usually starts automatically after
     install; if not, run "ollama serve")
  2. Double-click the desktop shortcut
  3. A brief console flash may appear, then the Raven window opens
  4. To stop the app, just close the Raven window

macOS:

A real app bundle named "Raven.app" is included in this folder, with the
Raven icon already set. Double-clicking it launches the server invisibly
in the background and opens Raven in its own window - no Terminal window
appears at any point, since macOS runs app bundles directly rather than
through a shell.

First double-click only: macOS Gatekeeper may show a warning since the
app isn't code-signed/notarized. If so, right-click (or Control-click)
"Raven.app" > Open, then click Open again to confirm. After that
one-time approval, double-clicking works normally.

Raven.app has to stay inside the repo folder - it finds ".venv" and the
Python code next to itself. To keep it handy without moving it:
  - Drag "Raven.app" onto the Dock, or
  - Right-click it in Finder > "Make Alias", then drag the alias (not
    the app itself) to your Desktop or into /Applications

To launch Raven going forward:
  1. Make sure Ollama is running (it usually starts automatically after
     install; if not, run "ollama serve")
  2. Double-click Raven.app (or its Dock/Desktop/Applications shortcut)
  3. The Raven window opens on its own - no terminal, no browser tab
  4. To stop the app, close the Raven window (or Cmd+Q). Avoid Force
     Quitting it from Activity Monitor - that skips the shutdown step
     and can leave the background server process running.

-----------------------------------------
SHARING WITH SOMEONE ELSE
-----------------------------------------

The Raven repo on GitHub is private, so a plain "here's the link" won't
let anyone else clone it - they'll get a 404/permission error until you
grant access.

  1. Go to https://github.com/mbaker-wv/raven/settings/access
  2. Click "Add people" and enter their GitHub username or email
  3. They'll get an email invite - they must accept it before cloning
     will work
  4. Send them this file (SETUP_INSTRUCTIONS.txt) - it has everything
     they need from here: installing Ollama, pulling the model, cloning
     the repo, and running the app. They can start at step 1 above.

If you'd rather not give them GitHub access, you can instead zip up the
project folder (skip the .venv and data folders - those are
machine-specific / contain your database) and send that directly, along
with this guide. If you also want your existing data to carry over
rather than them starting fresh, include ".raven.key" in that zip too
(it's a small hidden file in the project root) - see RESTORE.md.

-----------------------------------------
TROUBLESHOOTING
-----------------------------------------

"Could not reach Ollama at http://localhost:11434" error in the app:
    - Make sure Ollama is running: ollama serve
    - Make sure the model is pulled: ollama pull llama3.2:3b

Port 8000 already in use:
    - If you're running the app manually via uvicorn (step 4 in section
      3), pass a different port, e.g. --port 8001. The desktop launcher
      (section 4) handles this automatically - it picks a free port on
      its own if 8000 is taken.

Python version issues:
    - Check your version with: python --version    (Windows)
                                python3 --version   (macOS/Linux)
    - Raven requires Python 3.11+

macOS: "Raven.app cannot be opened because it is from an unidentified
developer":
    - Right-click (or Control-click) the file > Open, then confirm Open
      in the warning dialog. This is Gatekeeper blocking an unsigned app
      the first time, not a problem with the app itself - only needed
      once.
