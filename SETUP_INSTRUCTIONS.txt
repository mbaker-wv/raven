RAVEN - SETUP INSTRUCTIONS
===========================
Last updated: 2026-07-30

This guide covers four things:
  1. Installing Ollama (runs AI models locally on your machine)
  2. Installing the Llama 3.2 3B model
  3. Installing and running the Raven app
  4. Creating a desktop shortcut to launch it

-----------------------------------------
1. INSTALL OLLAMA
-----------------------------------------

Ollama lets you run AI models locally instead of calling a cloud API.

Windows:
  Option A - winget (recommended):
    1. Open PowerShell
    2. Run:
         winget install Ollama.Ollama
    3. Restart your terminal after install so PATH updates take effect.

  Option B - manual download:
    1. Go to https://ollama.com/download
    2. Download and run the Windows installer
    3. Follow the install prompts

macOS:
    1. Go to https://ollama.com/download
    2. Download the macOS app and drag it into Applications
    (or run: brew install ollama)

Linux:
    curl -fsSL https://ollama.com/install.sh | sh

Verify it installed correctly:
    ollama --version

Ollama runs as a background service. If it's not already running, start it with:
    ollama serve

By default it listens at http://localhost:11434

-----------------------------------------
2. INSTALL THE LLAMA 3.2 3B MODEL
-----------------------------------------

With Ollama installed and running, pull the model:

    ollama pull llama3.2:3b

This downloads the 3-billion-parameter Llama 3.2 model (a few GB, so it may
take a few minutes depending on your connection).

Confirm it's available:

    ollama list

You should see "llama3.2:3b" in the list.

Quick test (optional):

    ollama run llama3.2:3b

Type a prompt to confirm it responds, then type /bye to exit.

Note: Raven uses "llama3.2:3b" as its default model (set via the
OLLAMA_MODEL environment variable, or overridden per-agent in Admin), so no
extra configuration is needed once this model is pulled.

-----------------------------------------
3. INSTALL THE RAVEN APP
-----------------------------------------

Prerequisites:
    - Python 3.11 or later
        Download: https://www.python.org/downloads/
        (On the first install screen, check "Add python.exe to PATH"
        before clicking Install)
    - git
        Download: https://git-scm.com/downloads
        (Windows installer defaults are fine - just click through)
    - Ollama installed and running (see steps 1-2 above), OR a Claude API
      key if you plan to use Claude instead of local Ollama

Steps:

  1. Clone the repo (this is a private repo - see "SHARING WITH SOMEONE
     ELSE" below if you're setting this up for another person):
       git clone https://github.com/mbaker-wv/raven.git
       cd raven

  2. Create a virtual environment and install dependencies:

       Windows:
         python -m venv .venv
         .venv\Scripts\pip install -r requirements.txt

       macOS/Linux:
         python -m venv .venv
         .venv/bin/pip install -r requirements.txt

  3. (Optional) If restoring an existing database from backup instead of
     starting fresh, see RESTORE.md in this folder for the B2 restore steps.

  4. Run the app:

       Windows:
         .venv\Scripts\python -m uvicorn app.main:app --port 8000

       macOS/Linux:
         .venv/bin/python -m uvicorn app.main:app --port 8000

  5. Open your browser to:
       http://localhost:8000

Once running, go to Admin in the app to:
    - Confirm the AI provider is set to "ollama" (default) to use your
      local Llama 3.2 3B model, or switch to "claude" and add an API key
    - Set up Backblaze B2 backup credentials if desired

-----------------------------------------
4. CREATE A DESKTOP SHORTCUT
-----------------------------------------

A launcher file named "start_raven.bat" is included in this folder. It
starts the server and opens the app in your browser automatically.

To pin it to your desktop:

  1. Right-click "start_raven.bat" in this folder
  2. Choose "Show more options" (Windows 11) > "Send to" > "Desktop
     (create shortcut)"
     (On Windows 10, just "Send to" > "Desktop (create shortcut)")
  3. A shortcut named "start_raven.bat - Shortcut" will appear on your
     desktop. Rename it to "Raven" if you'd like.

Give it the Raven icon (included as "raven_icon.ico" in this folder):
  1. Right-click the desktop shortcut > Properties
  2. Click "Change Icon..."
  3. Click "Browse..." and select "raven_icon.ico" inside the folder you
     cloned the repo into (e.g. C:\path\to\raven\raven_icon.ico)
  4. Click OK > Apply

To launch Raven going forward:
  1. Make sure Ollama is running (it usually starts automatically after
     install; if not, run "ollama serve")
  2. Double-click the desktop shortcut
  3. A console window opens and your browser loads http://localhost:8000
  4. To stop the app, close the console window (or press Ctrl+C in it)

-----------------------------------------
SHARING WITH SOMEONE ELSE
-----------------------------------------

The Raven repo on GitHub is private, so a plain "here's the link" won't
let anyone else clone it - they'll get a 404/permission error until you
grant access.

  1. Go to https://github.com/mbaker-wv/raven/settings/access
  2. Click "Add people" and enter their GitHub username or email
  3. They'll get an email invite - they must accept it before cloning
     will work
  4. Send them this file (SETUP_INSTRUCTIONS.txt) - it has everything
     they need from here: installing Ollama, pulling the model, cloning
     the repo, and running the app. They can start at step 1 above.

If you'd rather not give them GitHub access, you can instead zip up the
project folder (skip the .venv and data folders - those are
machine-specific / contain your database) and send that directly, along
with this guide.

-----------------------------------------
TROUBLESHOOTING
-----------------------------------------

"Could not reach Ollama at http://localhost:11434" error in the app:
    - Make sure Ollama is running: ollama serve
    - Make sure the model is pulled: ollama pull llama3.2:3b

Port 8000 already in use:
    - Run uvicorn with a different port, e.g. --port 8001

Python version issues:
    - Check your version with: python --version
    - Raven requires Python 3.11+
